# Logbook Program

## Overview
This is a web-based time logging application that allows users to record timestamps with optional notes. It's designed as a Progressive Web App (PWA) with offline capabilities.

## Files
- `logbook.html` - Main application file containing HTML, CSS, and JavaScript
- `sw.js` - Service Worker for PWA functionality
- `manifest.json` - Web App Manifest
- `package.json` - Node.js package configuration
- `timeLogger.spec.js` - Test specifications
- Various icon and asset files

## Testing
- `make test` for running tests
